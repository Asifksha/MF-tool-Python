# MF-tool-Python :

mftool is a library for getting real time Mutual Funds data in India. It can be used in various types of projects which requires getting live quotes for a given mutual fund scheme or build large data sets for further data analytics.

What is Mutual Fund:

Mutual Funds pool money from investors and then invest them in a basket of securities such as stocks, bonds, debt, etc. An investor can invest in a Mutual Fund by buying its units and can earn a profit/loss by selling these units at a higher/lower price. The price of these units is called NAV(Net Asset Value) and is determined by the AUM(Assets under Management) and the units issued.
